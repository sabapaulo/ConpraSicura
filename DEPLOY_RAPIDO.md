## 🚀 COMECE AGORA

### **1. GITHUB - Upload do Código**

```bash
# Abra terminal/PowerShell na pasta do projeto
cd comprasicura

# Configure git
git config --global user.name "Seu Nome"
git config --global user.email "comprasicurax@gmail.com"

# Inicialize
git init
git add .
git commit -m "CompraSicura - Pronto para deploy"
git branch -M main
git remote add origin https://github.com/SEU_USERNAME/comprasicura.git
git push -u origin main
```

### **2. VERCEL - Deploy Automático**

1. Vá em: **vercel.com**
2. Clique: **Sign Up** → **GitHub**
3. Autorize
4. Clique: **Add New** → **Project**
5. Selecione: **comprasicura**
6. Clique: **Deploy**

**PRONTO!** 🎉

---

## 📍 SEU SITE FICOU ONLINE EM:

https://comprasicura-SEU_USERNAME.vercel.app

## 🌐 ADICIONE DOMÍNIO (OPCIONAL)

3. Adicione seu domínio
4. Siga instruções para apontar DNS
